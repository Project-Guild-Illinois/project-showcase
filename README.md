# Project Guild — Project Showcase

A public showcase of projects being built through Project Guild at the University of Illinois.

## CU-NightLink

A campus night-mobility product for UIUC students.

**Status:** Private MVP development; preparing for deployment and an initial student pilot.

CU-NightLink is designed to make late-night transportation decisions easier by helping students compare available options and coordinate temporary group travel when useful.
